\subsection{Not Ready to Record}
Make sure you have configured everything that needs to be configured (cameras, recording, grimace analysis).
The message at the bottom of the window should give you a hint to what is missing.

\subsection{Camera device is not in the dropdown selection}
Make sure the cameras are connected as described under \ref{connecting_the_cameras}\\
Make sure the switch you are using supports power over ethernet (PoE).\\
You cannot select the same camera device for both the top and the front. If you have configured the device for the top, you need to remove it or change it to a different device first before you can select this device for the front camera and vice versa.

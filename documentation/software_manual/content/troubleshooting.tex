\subsection{Not Ready to Record}
Make sure you have configured everything that needs to be configured (cameras, recording, grimace analysis).
The message at the bottom of the window should give you a hint to what is missing.

\subsection{I cannot find my Camera device in the dropdown selection}
Make sure the cameras are connected as described under \ref{connecting_the_cameras}\\
Make sure the switch you are using supports power over ethernet (PoE).\\
Make sure the switch's power cord is plugged into the power socket.\\
You cannot select the same camera device for both the top and the front.
If you have configured the device for the top, you need to remove it or change it to a different device first before you can select this device for the front camera and vice versa.

\subsection{I cannot find the results of my recordings}
The video files and analysis results are located in the folder you specified under: \[Recording \rightarrow Configure\ Files\]
See: \ref{configuring_the_output_files}.

If you forgot to change the target folder, the files were probably put into the folder you have used last,
or the folder that was specified in the configuration file you loaded.
This folder may have contained older recording files.
In this case, the numbers in the names of the new recording files should begin where the old recordings left off.
(If there were 5 recordings already stored in that folder (numbers 1 to 5), the new recordings should begin at recording number 6)
If you do not remember which recordings are the new ones, check when the files were last modified to identify
the new recordings and copy them into a different folder, so they don't get mixed up.
You can then correct the recording numbers in the filenames manually.

If the analysis results files are missing (\verb!grimace_results_*.csv!), you may have forgot to enable the grimace analysis under: \[Analysis \rightarrow Configure\ Grimace\ Analysis\]
See: \ref{configuring_the_grimace_analysis}.

As long as you have the video files, you can still do the analysis later, so nothing is lost in this case.
